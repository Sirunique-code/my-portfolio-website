# Thaddeaus Samuel - Personal Portfolio Website

A modern, high-performance portfolio website for **Thaddeaus Samuel** — Graphic Designer & Web Developer. Built with **React 18**, **Vite 6**, and **Tailwind CSS**.

Featuring ultra-responsive layouts, 3D character reaction loops, dynamic project showcase, working Formspree contact form, and dual Dark/Light mode theme.

## 🛠️ Project Commands

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

All content, copy, links, and media can be configured in [`src/data/portfolioData.js`](file:///c:/Users/USER/Documents/Thaddeaus-portfolio/src/data/portfolioData.js).
