# Dean Portfolio Website Clone

A high-fidelity clone of the **Dean** Framer Portfolio template, built with **React**, **Vite**, and **Tailwind CSS**. It replicates all structures, colors, typography, micro-interactions, responsive breakpoints, character reaction video loops, and dynamic pages.

---

## 🚀 Live Preview
The preview server is running locally at:
👉 **[http://localhost:4173/](http://localhost:4173/)**

---

## ✨ Features & Elements Included

1. **Header & Navigation**:
   - Floating pill glassmorphic navigation bar with blur backdrop.
   - Profile avatar with live pulsating green status dot (`Available for work`).
   - Theme toggle (Smooth transition between Dark `#0f0f0f` and Light `#ffffff` modes).
   - Dynamic CTA button with live status and directional arrow (`i Want to Chat`).
   - Responsive mobile hamburger menu with full animated drawer.

2. **Hero Section**:
   - Status badge: `Hi, I'm Dean` with star icon.
   - Signature ultra-condensed typography: `GRAPHICS DESIGNER` using **Big Shoulders Display**.
   - Interactive 3D Mascot Character video loop (`EtFNVEIQDKsxeDVfagwYxBQgg.mp4`) with poster fallback.
   - Interactive filter role pills (`GRAPHICS`, `WEB`, `PRODUCT`).
   - Action buttons with smooth scroll transitions to Projects and Contact.

3. **Metrics & Statistics**:
   - `1+` Projects Completed
   - `4+` Years of Experience
   - `5.0` Star Client Reviews
   - `100%` Client Retention Rate

4. **Projects Showcase**:
   - Card grid with zoom effects on hover, categories, client info, and case study links.
   - Full case studies included:
     - **Habitate** (`/projects/habitate`): Home renovation platform
     - **Pixel store** (`/projects/pixel-store`): Digital goods storefront
     - **Shipit** (`/projects/shipit`): Modern logistics solution
     - **Hifi Store** (`/projects/hifi-store`): Audio brand eCommerce
   - Animated benefits ticker / marquee banner.

5. **About & Experience**:
   - Professional bio and value proposition.
   - **My Stack**: Interactive cards for Framer, Figma, Photoshop, and Contra with official iconography.
   - **My Experience**: Timeline cards detailing roles at Google, Base, and Sero.

6. **Services**:
   - Numbered service cards: `01 WEB DESIGN`, `02 BRANDING`, `03 PRODUCT DESIGN`, `04 GRAPHICS DESIGN`.
   - Comprehensive deliverables badges with checkmarks.
   - Dedicated `/services` subpage with packages and ticker.

7. **Process**:
   - 3-step design workflow: `01 Let's Talk`, `02 Create & Refine`, `03 Deliver & Launch`.
   - Character reaction video clips corresponding to each phase.
   - `Ready to Get Started?` banner card with circular character video loop.

8. **Testimonial & Social Proof**:
   - 5-star rating display, client quote, author avatar, and studio affiliation.

9. **FAQ Accordion**:
   - Interactive open/close accordion with smooth rotation and clean borders.

10. **Contact & Booking**:
    - Direct email card with one-click copy and instant `Copied!` feedback.
    - Phone / WhatsApp call link.
    - Discovery consultation booking callout.
    - Working contact form with validation and animated success feedback.

11. **Footer**:
    - Giant uppercase `START A PROJECT` banner button.
    - Navigation, social links (Dribbble, X, Instagram, LinkedIn, Facebook), and back-to-top button.

## 🎨 Design System

| Element | Specification |
|---|---|
| **Display Font** | `Big Shoulders Display` (Google Fonts, 100..900) |
| **Body / UI Font**| `Host Grotesk` & `Inter` (Google Fonts) |
| **Dark Theme BG** | `#0f0f0f` |
| **Dark Theme Surface** | `#1c1c1c` & `#242424` |
| **Dark Theme Border** | `#303030` & `#3a3a3a` |
| **Light Theme BG** | `#ffffff` |
| **Light Theme Surface** | `#f2f2f2` & `#f0f0f0` |
| **Accent Cyan** | `#08b9d4` (Light) / `#00bdf1` (Dark) |
| **Accent Green** | `#44c92c` (Online status) |
